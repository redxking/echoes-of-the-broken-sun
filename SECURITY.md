# Security policy

**Author and owner:** Angelis Pseftis

This project is in development. No supported release series or security-response service level is declared
here. Development versions and historical test records do not establish production security qualification.

A verified private vulnerability-reporting channel has not yet been documented. Contact the project owner
through an already established private channel to arrange a secure report. Do not publish credentials,
private saves, personal data, or sensitive exploit details in a public issue. No response deadline is promised.

A useful report identifies the source commit or package hash, environment, affected component, observed
behavior, expected behavior, and minimal authorized reproduction steps. State whether the finding is
source inspection, a reproduced local issue, or an unverified hypothesis. Share only the data needed to
reproduce the issue and redact secrets.

Project agents follow [AGENTS.md](AGENTS.md), the applicable security/privacy skill, and current task
authorization. Record confirmed findings and their evidence boundaries without inferring exploitation,
compromise, release readiness, or a completed fix from a report alone.
