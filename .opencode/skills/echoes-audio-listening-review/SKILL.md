# Echoes audio listening review

## Project authority

Follow [Project/AGENTS.md](../../../AGENTS.md) and the authority map in [Docs/README.md](../../../Docs/README.md). Read the affected [Requirements.md](../../../Docs/Requirements.md) and [RequirementsState.md](../../../Docs/RequirementsState.md).

Use [AgentSkillRouting.md](../../../Docs/AgentSkillRouting.md) for skill selection, path ownership, heavy-run coordination, and evidence handling.

Read `Docs/AudioDirection.md`, the audio rules in `Docs/Archive/DevelopmentBible.md`, Track C in `Docs/GameCompletionDirective.md`, `Docs/Archive/ProjectLedger.md`, `Docs/Archive/AssetRegister.md`, the package identity, and [echoes-session-control](../echoes-session-control/SKILL.md). Use an actual audio output/listening path and live rendered gameplay; waveforms, logs, or screenshots alone do not prove player-perceived audibility. If audio cannot be heard through the available interface, stop and request a human/listening tool.

Sample title, briefing, ambience, selection/command acknowledgement, rejected action, combat concurrency, Well, menu, voice/subtitle synchronization, cinematics, result, mute/volume categories, reduced dynamic range, and pause. Record output device, level/settings, route, timestamp, observed cue, masking/dropout/latency, subtitle relation, and defects. Check that every claimed setting changes behavior.

Keep loudness, true-peak, and mix compliance as separate measured gates. Agent listening is not broad human-audience or owner acceptance; do not add or approve voices/assets without registered rights/provenance.

Before any live listening session, read [echoes-heavy-run-coordination](../echoes-heavy-run-coordination/SKILL.md), confirm an exclusive resource reservation, and record and release the reservation. Stop if no current reservation exists. Route package identity via `echoes-package-provenance`, measurement via `echoes-performance-profiling`, and owner testing via `echoes-human-acceptance-session`.

Before production or review, read the applicable master requirement and its linked context brief; when in scope, apply `SPEC-VISD-008` and `SPEC-ART-004` as written. Do not infer unapproved detail, motion, sound, or role meaning.
