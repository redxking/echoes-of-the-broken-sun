# Echoes localization readiness

## Project authority

Follow [Project/AGENTS.md](../../../AGENTS.md) and the authority map in [Docs/README.md](../../../Docs/README.md). Read the affected [Requirements.md](../../../Docs/Requirements.md) and [RequirementsState.md](../../../Docs/RequirementsState.md).

Use [AgentSkillRouting.md](../../../Docs/AgentSkillRouting.md) for skill selection, path ownership, heavy-run coordination, and evidence handling.

Read [Project/AGENTS.md](../../../AGENTS.md), `Docs/Archive/DevelopmentBible.md`, `Docs/Archive/TechnicalArchitecture.md`, `Docs/Archive/ProjectLedger.md`, `Docs/Archive/AssetRegister.md`, `Docs/Archive/SetupAndBuild.md`, authoritative narrative/UI sources, and [echoes-session-control](../echoes-session-control/SKILL.md). Do not write without a current task ownership.

Audit source-of-truth text, stable IDs, placeholder integrity, UI expansion/RTL/font risks, subtitles, voice dependency, and locale ownership. Never invent translated copy, alter digest-verified mission canon, or represent a readiness assessment as a localized build. Translation/vendor/rights decisions require owner authorization and must be recorded before source use.

Acceptance: locale-readiness matrix, blocked decisions, extraction/layout observations, source/generated boundary, and bounded evidence. Editor/runtime checks require an exclusive resource reservation through [echoes-heavy-run-coordination](../echoes-heavy-run-coordination/SKILL.md); route accessibility UI checks to `echoes-ui-accessibility-playtest` and evidence to `echoes-evidence-gate-review`. Stop when source IDs are unstable, canonical ownership is absent, rights/locale owner is unknown, or execution cannot observe layout.
