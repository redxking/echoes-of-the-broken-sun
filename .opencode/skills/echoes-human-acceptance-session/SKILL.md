# Echoes human acceptance session

## Project authority

Follow [Project/AGENTS.md](../../../AGENTS.md) and the authority map in [Docs/README.md](../../../Docs/README.md). Read the affected [Requirements.md](../../../Docs/Requirements.md) and [RequirementsState.md](../../../Docs/RequirementsState.md).

Use [AgentSkillRouting.md](../../../Docs/AgentSkillRouting.md) for skill selection, path ownership, heavy-run coordination, and evidence handling.

Read `Docs/DemoRecoveryDirective.md`, `Docs/Requirements.md`, `Docs/GameCompletionDirective.md`, `Docs/Requirements.md`, `Docs/Archive/ProjectLedger.md`, `Docs/Archive/SetupAndBuild.md`, the exact package/signing identity, `echoes-security-privacy`, and [echoes-session-control](../echoes-session-control/SKILL.md). This skill prepares the session and evidence; it does not authorize recruiting, recording people, collecting personal data, publishing results, or changing release state. Obtain explicit owner direction and participant consent before any such activity.

Use a verified package on the declared clean/known machine. Define participant familiarity, starting state, scenario, success/stop criteria, accessibility setup, observer role, permitted help, data retained, and defect triage. The participant uses normal visible player surfaces with mouse and keyboard; no Unreal MCP, console, debug flag, source knowledge, injected save, or scripted automation substitutes.

Record package/commit/signature, machine, date, participant role/familiarity only as consented, inputs/outcomes, observed confusion, failures, timing, audio/visual defects, and limitations. Keep agent-operated sessions separate as rendered evidence. Only Angelis may write or authorize `HUMAN ACCEPTED` or `HUMAN REJECTED — CHANGES REQUIRED`; a participant completion or internal review does not itself close a requirement or verification gate.

Before any clean-machine, GUI, player, audio, or visual session, read [echoes-heavy-run-coordination](../echoes-heavy-run-coordination/SKILL.md), confirm an exclusive resource reservation, then record and release the reservation. No stale or unconfirmed reservation is valid. Use `echoes-clean-machine-install-qualification` for clean-machine procedure and `echoes-evidence-gate-review` for state classification.
