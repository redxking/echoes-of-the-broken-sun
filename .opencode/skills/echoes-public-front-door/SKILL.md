# Echoes public front door

Read `Docs/GameCompletionDirective.md` Track J, `Docs/Archive/DevelopmentBible.md`, `Docs/Archive/ProjectLedger.md`, `Docs/Archive/AssetRegister.md`, and `../WorkstreamControl/ACTIVE_LANES.md` before changing a public surface. The public experience must carry Soryn/Crownfall/Future Wells and the game’s visual and narrative language without inventing lore, release state, player counts, reviews, platforms, or capabilities.

Map every claim to current ledger evidence. Describe planned, prototype, packaged, signed, notarized, and publicly available states distinctly. Use registered or licensed assets only; record any asset-family exception before use. Check keyboard access, labels, contrast, focus, responsive layouts, captions/alt text, and failure states.

Inspect the rendered surface on real browser dimensions, not source markup alone. Keep captures, URLs/build identity, viewport, observations, defects, and claim boundary. Publishing, analytics, accounts, purchases, or external communication require separate owner authority.

For rendered browser/game review, read `../WorkstreamControl/HEAVY_RUN_LOCK.md`, acquire a current detailed lease, and explicitly release it. Never reuse a stale or self-invented lease.
