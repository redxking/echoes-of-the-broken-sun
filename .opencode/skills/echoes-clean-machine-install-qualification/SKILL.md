# Echoes clean-machine install qualification

## Project authority

Follow [Project/AGENTS.md](../../../AGENTS.md) and the authority map in [Docs/README.md](../../../Docs/README.md). Read the affected [Requirements.md](../../../Docs/Requirements.md) and [RequirementsState.md](../../../Docs/RequirementsState.md).

Use [AgentSkillRouting.md](../../../Docs/AgentSkillRouting.md) for skill selection, path ownership, heavy-run coordination, and evidence handling.

Read `Docs/GameCompletionDirective.md` Gate 44 and clean-machine procedure, `Docs/Requirements.md`, `Docs/Archive/SetupAndBuild.md`, `Docs/Archive/ProjectLedger.md`, the current task handoff, [echoes-session-control](../echoes-session-control/SKILL.md), [echoes-heavy-run-coordination](../echoes-heavy-run-coordination/SKILL.md), and the exact package/signing records. Require a callable GUI-control interface with fresh visible state/screenshots and actual mouse/keyboard events, or stop and request a human/tool. This action needs an exclusive resource reservation; acquire it through the live control process and record and release the reservation after the session.

Document the separate machine, Apple Silicon/macOS identity, clean-state basis, installer hash, signature/notarization assessment, account boundary, display, network condition, and time. Prove the Seagate development/archive volume is absent. Install and launch normally through visible macOS player surfaces; no terminal, Unreal MCP, debugger, injected save, debug flag, or source shortcut. Retain first-launch timing, reach the title, play a complete skirmish through a visible terminal outcome, create a normal player save, quit cleanly, relaunch normally, load that save through the rendered UI, verify recovered player-visible state, exit, and inspect residue.

Retain paths, hashes, first-launch timing, input/state/audio observations, skirmish result, save identity, relaunch/load result, defects, and exact boundary. Agent-operated GUI proof is not unfamiliar-human acceptance; do not claim clean-machine qualification if the machine, absent-Seagate condition, candidate identity, complete skirmish, or save/relaunch/load path is unproven.

Additional device/OS checks are separate named sessions with their own package identity, clean-state basis, evidence, and authorization; one machine does not establish compatibility across the fleet.
